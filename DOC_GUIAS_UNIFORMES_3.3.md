# Guías uniformes TEMPLE 3.3

## Colección

Treinta variantes con figuras anatómicas ilustradas del mismo estilo: grafito gris, coral para regiones principales, salvia para indicaciones y fondo marfil. Diez láminas agrupan tres pares de figuras cada una; el visor presenta únicamente el par del ejercicio elegido. Los archivos originales se conservan intactos, y el encuadre lo hace el componente de la interfaz. Los divisores de cada lámina determinan los encuadres para no cortar figuras cuando las filas tienen alturas ligeramente distintas.

Se reemplazó la colección mixta y se retiró su carga desde el visor. Esta distribución no contiene fotografías de ejercicios ni escaneos del manual. `anatomy-data.js` contiene músculos, fases, referencia de consulta cuando existe y límites del encuadre. `anatomy.js` relaciona nombres de rutina, alternativas por equipamiento y catálogo. No se realiza ninguna descarga externa de imágenes durante el uso.

## Manual e ilustraciones originales

La referencia de consulta es el ejemplar aportado de Frédéric Delavier, Strength Training Anatomy, segunda edición. Se consultaron las láminas disponibles de flexiones, curl, remos, pantorrillas y puente; sus páginas se indican como referencia dentro de las guías correspondientes. Algunas variantes actuales son diferentes (por ejemplo curl de pie frente a sentado, pantorrillas bilateral frente a unilateral). La app no muestra la lámina del libro como si fuera una variante exacta.

Las ilustraciones de esta colección fueron generadas con IA para TEMPLE usando una primera lámina original como referencia de estilo para las restantes. Se revisaron visualmente posiciones, equipamiento, color y encuadre; se solicitaron correcciones de señales de movimiento y algunas regiones/poses. No se atribuye la autoría de estas imágenes a Delavier ni se presentan como una reproducción validada del manual. La traducción del libro completo no forma parte de esta actualización.

## Interpretación

Rojo indica regiones musculares principales, de forma simplificada. No es una medición de activación, esfuerzo, crecimiento o recuperación. La ropa y la perspectiva pueden ocultar parte de una región. Las flechas y los rótulos ayudan a interpretar la secuencia. Las planchas se mantienen respirando: la primera figura muestra preparación, no una repetición alternada. Algunas figuras de movilidad representan un ejemplo dentro del calentamiento, no su duración completa.

Las guías son educativas; no tienen revisión anatómica clínica independiente ni valor de evaluación de técnica. Las instrucciones escritas especifican la variante y el movimiento. Para variantes desconocidas se indica que no hay una ilustración específica, en lugar de mostrar un ejercicio genérico no relacionado.

## Verificación

Cobertura automatizada de las cuatro rutinas con seis combinaciones de equipamiento, las 30 entradas, archivos presentes y límites de encuadre. Regresión de separación de perfiles, registro retrospectivo, suplementos y exportación/importación. Prueba de navegación en el catálogo y ampliación en navegador con perfil ficticio. La caché precarga las diez láminas, el catálogo y el visor. Instalar y usar en un teléfono físico sigue requiriendo comprobación en ese dispositivo.
