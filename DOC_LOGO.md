# Isotipo integrado

Se utilizó la herramienta integrada de generación/edición de imágenes para adaptar el isotipo de las tres piedras previamente elegido a fondo transparente. La exportación a 192/512 solo cambia el tamaño del PNG. El archivo usado en la app es `logo.png`.

Prompt de adaptación:

> Edit target: the selected TEMPLE isotipo. Preserve exactly the same three stacked stone shapes, their contours, spacing, orientation, graphite and sage colors. Remove the entire ivory background and make it genuinely transparent. No text, no redesign, no new elements, no shadow. Center the unchanged mark with only a modest 10% margin on all sides, a square canvas, suitable for a mobile app header and icon. Maintain crisp original contours.
