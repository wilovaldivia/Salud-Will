# Imágenes de ejercicios — colección 3.3

La colección mixta de versiones anteriores fue sustituida por diez láminas originales generadas con IA para TEMPLE el 20 de octubre de 2026, con 30 variantes y un único sistema visual. Se conserva cada archivo PNG original; la selección de filas se realiza en la interfaz.

No se incluyen las imágenes anteriores de wger/Wikimedia ni las páginas escaneadas de Delavier. Sus atribuciones de versiones previas no describen las nuevas imágenes. Para las referencias de consulta al manual y la interpretación de los colores, ver GUIAS_UNIFORMES_3.3.md.

El isotipo de TEMPLE mantiene su documentación separada en LOGO.md. No se atribuye al autor del manual la creación o aprobación de las nuevas ilustraciones.
